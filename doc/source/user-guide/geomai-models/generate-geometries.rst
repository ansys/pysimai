Generate geometries with a GeomAI model
=======================================

**Applies to:** GeomAI models

To generate a geometry with a trained GeomAI model, pass a
:class:`~ansys.simai.core.data.geomai.predictions.GeomAIPredictionConfiguration` object with latent
parameters to
:meth:`geomai_client.predictions.run()<ansys.simai.core.data.geomai.predictions.GeomAIPredictionDirectory.run>`,
or call
:meth:`geomai_client.predictions.sample()<ansys.simai.core.data.geomai.predictions.GeomAIPredictionDirectory.sample>`
for a random geometry. Each call returns a
:class:`~ansys.simai.core.data.geomai.predictions.GeomAIPrediction` object that you download as a
``.vtp`` file.

Script to generate geometries with a GeomAI model
-------------------------------------------------

This script generates five geometries from random latent parameters and downloads them.

.. code-block:: python

   import os
   import random

   import ansys.simai.core as asc
   from ansys.simai.core.data.geomai.predictions import GeomAIPredictionConfiguration
   from ansys.simai.core.errors import ProcessingError

   OUTPUT_DIR = "random_geometries"
   NUM_GEOMETRIES = 5

   simai_client = asc.SimAIClient(organization="<your_organization>")
   geomai_client = simai_client.geomai

   workspace = geomai_client.workspaces.get(name="<your_workspace_name>")

   # Generate a geometry from latent parameters with a GeomAI model
   # The length of the latent vectors of the training data gives the number of latent parameters.
   latent_dict = workspace.get_latent_parameters()
   nb_latent_params = len(next(iter(latent_dict.values())))

   os.makedirs(OUTPUT_DIR, exist_ok=True)

   # Generate a random geometry with a GeomAI model
   predictions = []
   for i in range(NUM_GEOMETRIES):
       # Draw each latent parameter from a standard normal distribution.
       latent_params = [random.gauss(0, 1) for _ in range(nb_latent_params)]
       config = GeomAIPredictionConfiguration(latent_params=latent_params)
       predictions.append(geomai_client.predictions.run(config, workspace))

   for i, prediction in enumerate(predictions):
       try:
           if not prediction.wait(timeout=600):
               print(f"Prediction {i + 1} timed out.")
               continue
       except ProcessingError:
           print(f"Prediction {i + 1} failed: {prediction.failure_reason}")
           continue
       output_path = os.path.join(OUTPUT_DIR, f"random_{i + 1:02d}_{prediction.id}.vtp")

       # Download a geometry generated by a GeomAI model
       prediction.download(output_path)
       print(f"Saved geometry to {output_path}")

Generate a random geometry with a GeomAI model
----------------------------------------------

The ``sample()`` method is the simplest way to see what a GeomAI model can produce. It picks random
latent parameters with a sampling strategy that stays within the bounds of the training data:

.. code-block:: python

   prediction = geomai_client.predictions.sample(workspace=workspace)
   prediction.download("sample.vtp")

``sample()`` also accepts a ``resolution`` argument. Without it, the resolution is set
automatically from the closest training geometry.

.. warning::
   The ``sample()`` method is in beta. It is likely to be recast or retired by December 2026.
   Testing and feedback are encouraged, but don't include it in a production workflow.

Generate a geometry from latent parameters with a GeomAI model
--------------------------------------------------------------

For more control, choose the position of the new geometry in the latent space. Each training
geometry has a latent vector, and a new latent vector gives a new geometry:

.. code-block:: python

   config = GeomAIPredictionConfiguration(latent_params=latent_params)
   prediction = geomai_client.predictions.run(config, workspace)

Follow these rules for ``latent_params``:

- The number of floats must be lower than or equal to the ``nb_latent_param`` value of the GeomAI
  model, 512 by default. For a shorter list, see :ref:`reduced_latent_space_geomai`.
- Latent parameters typically range from -3 to +3 for meaningful results. Values far from the
  latent parameters of the training data can give garbled or void geometries. To see their
  distribution, plot the latent parameters of the training data.
- To get the latent parameters of all training geometries, call
  :meth:`workspace.get_latent_parameters()<ansys.simai.core.data.geomai.workspaces.GeomAIWorkspace.get_latent_parameters>`.
  It returns a dictionary that maps each geometry name to its latent vector. Use these vectors as
  reference points for exploration and interpolation.

``geomai_client.predictions.run()`` also accepts the configuration as a dictionary, for example
``dict(latent_params=[0.1, 1.2, 0.76])``. If you don't pass ``workspace``, the prediction runs in
the current workspace of the client.

Download a geometry generated by a GeomAI model
-----------------------------------------------

A prediction of a GeomAI model produces a ``.vtp`` file. Wait for the prediction, then download the file with
:meth:`prediction.download()<ansys.simai.core.data.geomai.predictions.GeomAIPrediction.download>`.
``wait()`` returns ``False`` on timeout and raises :class:`~ansys.simai.core.errors.ProcessingError`
if the prediction fails:

.. code-block:: python

   try:
       if prediction.wait(timeout=600):
           prediction.download("<your_output_file>.vtp")
       else:
           print("Prediction timed out.")
   except ProcessingError:
       print(f"Prediction failed: {prediction.failure_reason}")

``prediction.download()`` waits for the prediction before it downloads. You can also download by ID
with ``geomai_client.predictions.download(prediction.id, "<your_output_file>.vtp")``, which doesn't
wait.

You can use the downloaded ``.vtp`` files in your usual solver, as training data or prediction
input for a SimAI model, or for other postprocessing.

.. _ref_geomai_resolution_section:

Set the resolution of a generated geometry
------------------------------------------

The ``resolution`` parameter of ``GeomAIPredictionConfiguration`` is a tuple of three integers
``(x, y, z)``, the number of voxels along each axis. By default, it's set automatically from the
training data.

- Low resolution, for example ``(50, 50, 50)``: fast generation, for quick previews.
- Medium resolution, for example ``(100, 100, 100)``: a good balance for most use cases.
- High resolution, for example ``(300, 300, 300)`` or more: captures fine details and sharp edges.

.. code-block:: python

   config = GeomAIPredictionConfiguration(
       latent_params=latent_params,
       resolution=(300, 300, 300),
   )

The total number of voxels must not exceed 900 :sup:`3`, that is,
``x * y * z <= 729,000,000``. A larger value raises an error. At the maximum resolution, a
prediction takes about 10 minutes.

.. tip::
   If generated geometries have the right shape but lack sharpness or have an unexpected number of
   disconnected parts, increase the resolution.

.. _reduced_latent_space_geomai:

Work with a reduced latent space of a GeomAI model
--------------------------------------------------

A GeomAI model orders latent dimensions by importance. The first dimensions capture the largest
sources of variation in the training data, and later dimensions capture finer and finer details.
For exploration, interpolation, or optimization, you can often work with the first dimensions only.

To choose how many dimensions to keep, read the Parameter Importance section of the MER. If the
first 10 latent parameters account for most of the variance, ``n=10`` gives a compact space with
little loss of geometric fidelity. For more information on the MER, see
:doc:`/user-guide/geomai-models/evaluate-a-model`.

The ``n`` argument of ``workspace.get_latent_parameters()`` truncates each latent vector to its
first ``n`` values. ``n`` must not exceed the number of latent parameters of the GeomAI model.
Without ``n``, the method returns full latent vectors.

.. code-block:: python

   # All latent parameters
   full = workspace.get_latent_parameters()

   # Only the 10 most important latent parameters
   reduced = workspace.get_latent_parameters(n=10)

Pass a reduced latent vector directly to ``GeomAIPredictionConfiguration``. The remaining
dimensions are discarded automatically, so you don't need to handle them:

.. code-block:: python

   vec = list(reduced.values())[0]  # 10-element vector

   config = GeomAIPredictionConfiguration(latent_params=vec)
   prediction = geomai_client.predictions.run(config, workspace)

.. note::
   A reduced latent vector loses the information of the removed dimensions. Geometries generated
   from a reduced space are close approximations of the originals, not exact copies. The fewer
   dimensions you keep, the coarser the approximation.

Use a GeomAI model in an optimization workflow
----------------------------------------------

You can use a GeomAI model in an optimization workflow, for example with Ansys optiSLang, with the
latent parameters as design variables. A reduced latent space lowers the number of design
variables and speeds up convergence:

- Fewer dimensions make the optimization easier and faster to converge, but capture less geometric
  detail.
- More dimensions give finer control over the geometry, but make the optimization problem larger.

Use the Parameter Importance section of the MER to choose how many dimensions capture enough
geometric variation for your use case. To start an optimization from an existing design, project
the design onto the latent space first. See :doc:`/user-guide/geomai-models/interpolate-and-project`.

Expected result when you generate geometries with a GeomAI model
----------------------------------------------------------------

The complete script creates the ``random_geometries`` folder and prints one line for each
generated geometry, for example ``Saved geometry to random_geometries/random_01_<prediction_id>.vtp``.

Errors when you generate geometries with a GeomAI model
-------------------------------------------------------

.. list-table::
   :header-rows: 1
   :widths: 25 35 40

   * - Exception
     - Cause
     - Fix
   * - :class:`~ansys.simai.core.errors.ProcessingError`
     - The prediction failed.
     - Read ``prediction.failure_reason``. Check the number of latent parameters and the
       resolution.
   * - :class:`~ansys.simai.core.errors.InvalidArguments`
     - The configuration isn't valid, for example a resolution with a zero or negative value, or
       ``n`` larger than the number of latent parameters of the GeomAI model.
     - Fix the configuration or the value of ``n``.
   * - :class:`~ansys.simai.core.errors.NotFoundError`
     - No workspace has the requested name.
     - Check the workspace name with ``geomai_client.workspaces.list()``.
