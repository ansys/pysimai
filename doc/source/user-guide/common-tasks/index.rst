Tasks for all model types
=========================

These pages apply to both SimAI models and GeomAI models.

- :doc:`/user-guide/common-tasks/work-asynchronously`: wait for training data, model builds, geometries,
  and predictions, and send many requests at once.
- :doc:`/user-guide/common-tasks/handle-errors`: catch PySimAI exceptions and fix their causes.
- :doc:`/user-guide/common-tasks/manage-resources`: list, rename, and delete projects, workspaces,
  geometries, predictions, and training data.
- :doc:`/user-guide/common-tasks/migrate-from-deprecated-features`: find the replacement of each deprecated
  feature, and check planned changes and removed features.
