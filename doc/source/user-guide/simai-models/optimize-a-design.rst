Optimize a design with a SimAI model
====================================

**Applies to:** SimAI models

Deform a baseline geometry to minimize or maximize a global coefficient with
:meth:`OptimizationDirectory.run_non_parametric() <ansys.simai.core.data.optimizations.OptimizationDirectory.run_non_parametric>`,
then read the generated geometries and their objective values. For the concepts and the
workflow, see :doc:`/user-guide/simai-models/optimization-overview`.

Script to optimize a design with a SimAI model
----------------------------------------------

This script runs a non-parametric optimization of 10 iterations that maximizes one global
coefficient inside one bounding box, then prints the generated geometries and objective values.
Replace the bounding box, the maximum displacement, and the scalars with values that fit your
geometry and your SimAI model.

.. code-block:: python

   import ansys.simai.core as asc
   from ansys.simai.core.data.optimizations import Optimization
   from ansys.simai.core.errors import ProcessingError

   simai_client = asc.SimAIClient(organization="<your_organization>")

   # Prepare the optimization
   workspace = simai_client.workspaces.get(name="<your_workspace_name>")
   geometry = simai_client.geometries.get(name="<your_geometry_name>.vtp", workspace=workspace)

   # Opens a browser login prompt
   offline_token = simai_client.me.generate_offline_token()

   # Run the optimization
   optimization = simai_client.optimizations.run_non_parametric(
       geometry=geometry,
       offline_token=offline_token,
       bounding_boxes=[[-0.07, 0.15, -0.06, 0.12, -0.09, 0.15]],
       max_displacement=[0.1],
       scalars={"<your_scalar_name>": 10.5},
       n_iters=10,
       maximize=["<your_global_coefficient_name>"],
       show_progress=True,
   )

   try:
       if isinstance(optimization, Optimization):
           # Server-side optimization: runs in the background
           optimization.wait()
           print(f"Optimization ID: {optimization.id}")
       else:
           # Legacy optimization: already finished
           print(f"Optimization ID: {optimization.optimization.id}")
       # Read the results of the optimization
       print(f"Generated geometries: {[geo.name for geo in optimization.list_geometries()]}")
       print(f"Objectives: {optimization.list_objectives()}")
   except ProcessingError as error:
       print(f"Optimization failed: {error}")

Prepare the optimization
------------------------

Before you run the optimization, you need:

- A workspace with a SimAI model whose model configuration defines the global coefficient to
  optimize. The global coefficient must be computed from surface fields.
- A baseline geometry in this workspace, which has been used to build the SimAI model. Choose one
  that's representative of your training data.
- One or more bounding boxes, as ``[xmin, xmax, ymin, ymax, zmin, zmax]`` in the coordinates of
  the geometry. Deformations happen only inside them.
- For a server-side optimization, an offline token and one maximum displacement per bounding
  box.

For how to choose each parameter, see :doc:`/user-guide/simai-models/configure-an-optimization`.

Run the optimization
--------------------

Call ``simai_client.optimizations.run_non_parametric()`` with the baseline geometry, as an object
or an ID, and set one objective: ``minimize`` or ``maximize``, each a list of one global
coefficient name. The optimization runs in the workspace of the geometry.

The type of the returned object depends on the SimAI model of the workspace:

- A server-side optimization returns an
  :class:`~ansys.simai.core.data.optimizations.Optimization` object right away. Call
  ``wait()`` to block until it ends. ``wait()`` raises
  :class:`~ansys.simai.core.errors.ProcessingError` if the optimization fails.
- A legacy optimization returns a
  :class:`~ansys.simai.core.data.optimizations.LegacyOptimizationResult` object once it has
  finished. It has no ``wait()`` method. Its ID is in ``optimization.optimization.id``.

Read the results of the optimization
------------------------------------

Both result types have the same two methods:

- ``list_geometries()`` returns the :class:`~ansys.simai.core.data.geometries.Geometry`
  objects generated by the optimization, one per iteration, in the workspace.
- ``list_objectives()`` returns the objective values of the iterations.

The generated geometries are regular geometries of the workspace. Run predictions and
postprocessings on them to compare them with the baseline:

.. code-block:: python

   for generated in optimization.list_geometries():
       prediction = generated.run_prediction(scalars={"<your_scalar_name>": 10.5})

For more information, see :doc:`/user-guide/simai-models/run-predictions`.

Retrieve the results of a past optimization
-------------------------------------------

Server-side optimizations stay on Ansys SimAI. To read their results later, from another script
or session, get them by ID with
:meth:`OptimizationDirectory.get() <ansys.simai.core.data.optimizations.OptimizationDirectory.get>`,
or list the optimizations of a workspace with
:meth:`OptimizationDirectory.list() <ansys.simai.core.data.optimizations.OptimizationDirectory.list>`,
which takes the workspace ID:

.. code-block:: python

   import ansys.simai.core as asc

   simai_client = asc.SimAIClient(organization="<your_organization>")
   workspace = simai_client.workspaces.get(name="<your_workspace_name>")

   for past in simai_client.optimizations.list(workspace_id=workspace.id):
       print(past.id, past.is_ready)

   optimization = simai_client.optimizations.get(id="<your_optimization_id>")
   optimization.wait()
   print(optimization.list_objectives())
   print([geo.name for geo in optimization.list_geometries()])

Both methods return :class:`~ansys.simai.core.data.optimizations.Optimization` objects. If the
optimization is still running, ``wait()`` blocks until it ends. The ``iteration_results`` property
gives the raw results of each iteration. To delete an optimization, call
``simai_client.optimizations.delete(optimization)``.

Expected result when you optimize a design with a SimAI model
-------------------------------------------------------------

The complete script prints the ID of the optimization, the names of the generated geometries, and
the list of objective values, one per iteration.

Errors when you optimize a design with a SimAI model
----------------------------------------------------

.. list-table::
   :header-rows: 1
   :widths: 25 40 35

   * - Exception
     - Cause
     - Fix
   * - :class:`~ansys.simai.core.errors.InvalidArguments`
     - A parameter is invalid: no offline token or no ``max_displacement`` for a server-side
       optimization, both or neither of ``minimize`` and ``maximize``, a bounding box that isn't
       six numbers with each minimum less than its maximum, or ``n_iters`` that isn't a positive
       integer.
     - Read the message, which names the parameter, and see
       :doc:`/user-guide/simai-models/configure-an-optimization`.
   * - :class:`~ansys.simai.core.errors.ProcessingError`
     - The server-side optimization failed.
     - Check the parameters, or try another baseline geometry.
   * - :class:`~ansys.simai.core.errors.NotFoundError`
     - No workspace, geometry, or optimization has this name or ID.
     - Check the name or the ID.
